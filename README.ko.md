# 업무 일정 관리 시스템

[繁體中文](./README.md) ・ [English](./README.en.md) ・ [日本語](./README.ja.md) ・ **한국어**

HTML 파일 하나로 동작하는 업무 일정 관리 도구입니다. 작업·회의·반복 항목·월간 캘린더·간트 차트가 모두 한 파일에 들어 있습니다. 내려받아 브라우저로 열기만 하면 바로 쓸 수 있습니다.

> 순수 프런트엔드. 의존성 없음, 설치 없음. Node.js도 서버도 데이터베이스도 필요하지 않습니다.

## 사용 방법

### 방법 1 — 단독 실행 (설치 불필요)

1. [`public/index.html`](./public/index.html) 내려받기
2. 아무 최신 브라우저로 열기

데이터는 해당 브라우저의 `localStorage`에 저장되며 새로 고쳐도 사라지지 않습니다.

### 방법 2 — Cloudflare 배포 (다중 사용자 + 기기 간 동기화)

```bash
npm install
npx wrangler d1 create work-schedule-db   # 이미 만들었다면 건너뛰고 id를 wrangler.jsonc에 기입
npm run db:init                            # 테이블 생성
```

Turnstile 위젯(봇 방지)을 만듭니다:

```bash
npx wrangler turnstile widget create "work-schedule" --domain <내-도메인> --domain localhost --domain 127.0.0.1 --mode managed
```

명령이 **sitekey**(공개용. `public/login.html`의 `SITEKEY`에 기입)와 **secret**(비밀)을 출력합니다.
이어서 두 개의 secret을 설정합니다:

```bash
npx wrangler secret put TURNSTILE_SECRET
```

```bash
npx wrangler secret put ADMIN_EMAILS
```

`ADMIN_EMAILS`는 관리자 이메일을 쉼표로 구분한 목록입니다. 목록에 있는 계정은 **가입 시점에 승인된 관리자가 됩니다**.
이것이 없으면 첫 계정을 승인할 사람이 없어 시스템이 교착 상태에 빠집니다.

> 이 둘을 `vars`가 아니라 secret으로 두는 이유: `vars`는 버전 관리에 포함되고(공개 저장소라면 이메일도 공개됩니다),
> 대시보드에서 수정한 `vars`는 다음 `deploy` 때 덮어써집니다.

마지막으로 배포합니다:

```bash
npm run deploy
```

**`TURNSTILE_SECRET`이 설정되지 않았을 때는 가입과 로그인이 모두 거부됩니다.** 그냥 통과시키면 봇 방지가 이름뿐인 장치가 되기 때문입니다.

로컬 개발에는 실제 키가 필요 없습니다. `.dev.vars`에 Cloudflare 공식 테스트 키가 들어 있습니다(이 파일은 gitignore 처리되어 있습니다).

### 배포 문제 해결

**가입 또는 로그인이 Error 1101(Worker threw exception)을 반환하는 경우** — Workers 운영 환경의 PBKDF2 반복 횟수 상한은 100,000이며, 초과하면 `NotSupportedError`가 발생합니다. 게다가 **로컬 workerd는 이 규칙을 강제하지 않아** 로컬에서는 재현되지 않습니다. 증상·조사 과정·수정은
[사고 기록: 운영 환경 가입이 항상 Error 1101을 반환](docs/postmortems/2026-07-30-register-error-1101.md)을 참고하세요.

## 기능

### 📋 일정
- **그룹**: 날짜가 없는 분류 라벨. 생성·이름 변경·삭제 가능
- **항목**: 세 가지 유형 — 🟢 작업, 🟣 회의, 🟠 과제. 셋 다 선택적인 시각과 **링크**(회의 URL, 문서 등. 목록에서 바로 열립니다)를 가질 수 있습니다
- **여러 날에 걸친 항목**: 반복이 아닌 항목에는 종료일을 지정할 수 있습니다(예: 8/22–8/26 출장). 기간 내 모든 날짜가 캘린더에 표시되고, 완료 상태는 기간 전체가 공유하며, 진행 중인 기간은 기한 초과로 계산하지 않습니다
- 연도 / 분기 / 월 / 특정 날짜의 네 가지 범위 필터
- **완료한 항목은 아래쪽 “완료” 영역으로 접힙니다.** 위쪽에는 아직 남은 일만 표시됩니다
- **반복 규칙**: 매주 / 격주(요일 복수 선택 가능), 매월(고정 날짜 또는 “N번째 O요일”), 분기별, 매년. 공휴일과 겹치면 다음 근무일로 미루거나 앞당기거나 조정하지 않을 수 있고, 종료일이나 반복 횟수도 지정할 수 있습니다
- 특정 회차만 날짜를 바꾸거나 건너뛸 수 있으며 다른 회차에는 영향을 주지 않습니다
- 사용자 지정 공휴일 목록(주말은 이미 공휴일로 처리): **공휴일을 한 번에 불러오기**(2026년 내장, 출처는 대만 행정원 인사행정총처의 공식 업무 달력) 또는 여러 날짜를 한 번에 붙여넣기
- 키워드(제목 또는 그룹)·유형·완료 여부에 따른 **검색과 필터**

### 📅 캘린더
- 오늘이 뚜렷하게 표시되는 월간 그리드
- 회의는 시각순으로 표시되고, 작업과 과제는 칸에서 바로 체크할 수 있습니다
- **휴대폰에서는 Google 캘린더 방식**을 따릅니다. 칸에는 그날 무엇이 있는지를 나타내는 색 점만 표시하고, 날짜를 누르면 아래에 전체 내용이 펼쳐집니다. 50px 폭의 칸에 서너 줄의 글자를 욱여넣어 봐야 휴대폰에서는 읽을 수 있는 정보가 되지 않습니다
- 날짜를 누르면 항목 카드와 **일일 기록** 칸이 펼쳐집니다(서식 지원, 아래 참고)

### 📊 프로젝트(간트 차트)
- 여러 프로젝트 관리. 진행률과 오늘 표시선이 있는 타임라인 막대
- **타임라인을 좌우로 스크롤**할 수 있고 주 / 월 / 분기 / 연의 네 단계로 확대·축소할 수 있어, 장기 프로젝트나 해를 넘기는 프로젝트도 읽을 수 있습니다. 연도 경계에는 뚜렷한 구분선이 있고 “오늘로 이동” 버튼도 있습니다
- 날짜와 진행률은 작업 표에서 바로 편집할 수 있고 차트에 즉시 반영됩니다
- 각 작업은 **하위 항목**으로 펼칠 수 있으며, 이 경우 진행률은 체크 상황에서 자동으로 계산됩니다(수동 입력 칸은 읽기 전용이 됩니다)
- 프로젝트는 드롭다운으로 전환합니다
- 프로젝트 메모는 자동 저장됩니다(서식 지원, 아래 참고)

### ✍️ 서식(일일 기록과 프로젝트 메모)
- 굵게·기울임·밑줄·취소선, 글머리 기호와 번호 목록, 형광펜·글자 색·글자 크기, 인용·링크·코드, 서식 지우기
- 도구 모음은 **기본적으로 접혀 있습니다.** `Ctrl+Shift+X` 또는 칸 아래 버튼으로 전환하며, 설정은 이 기기에 기억됩니다
- 웹에서 붙여넣은 내용은 자동으로 정리되어 지원되는 서식만 남습니다

### 🔔 대시보드와 알림
- 상단에 상시 표시: 오늘 할 일, 이번 주 할 일, 오늘의 회의, 기한 초과
- 페이지를 열면 오늘의 미완료 항목이 팝업으로 뜨고, 종 버튼에는 읽지 않은 개수가 표시됩니다
- 오른쪽 위에서 **밝게 / 어둡게** 전환. 기본값은 시스템 설정을 따릅니다
- 휴대폰에서는 내비게이션이 화면 아래에 고정되고, 폼과 대화상자는 터치에 맞게 조정되어 있습니다
- 오른쪽 위에서 **영어 / 번체 중국어** 인터페이스를 전환할 수 있습니다(기본값은 브라우저 언어를 따릅니다)

### 👥 사용자와 권한(배포 후 활성화)
- 사용자는 이메일과 비밀번호로 직접 가입합니다. 가입 페이지에는 Cloudflare Turnstile 봇 방지가 있습니다
- **가입 후 관리자 승인이 필요**하며, 승인되지 않은 계정은 세션을 받지 못합니다
- 역할은 두 가지: **사용자**(자기 일정만)와 **관리자**(계정 관리도 가능)
- 관리자는 계정 승인·거절·정지·삭제와 역할 변경을 할 수 있지만, **누구의 일정 내용도 볼 수 없습니다**
- 계정을 정지하거나 삭제하면 해당 사용자의 모든 기기가 즉시 로그아웃됩니다
- 비밀번호는 PBKDF2-SHA256(100,000회 반복, Workers 플랫폼 상한) 해시로 저장하며 평문은 남기지 않습니다
- 모든 계정은 **빈 화면**에서 시작하며 다른 사람의 데이터는 전혀 보이지 않습니다

### 🔗 공유(배포 후 활성화)

- 아무 항목, **그룹(그 아래 모든 항목 포함)**, 프로젝트에서 **🔗** 를 누르고 상대방 계정의 이메일을 입력합니다
- 권한은 두 단계: **보기 가능**(읽기 전용)과 **조작 가능**(완료·하위 항목 체크, 진행률 변경)
- 이름 변경·날짜 변경·삭제는 언제나 소유자만 할 수 있습니다
- 공유되는 것은 복사본이 아니라 같은 데이터이므로 양쪽이 항상 같은 것을 봅니다. 소유자는 언제든 회수할 수 있습니다
- 받은 공유는 “공유” 페이지에 모이며 내 일정이나 캘린더에 섞이지 않습니다
- **작업 기록**: 공유 항목을 누가 언제 바꿨는지 90일간 남습니다. “공유” 탭에는 읽지 않은 개수가 표시되고, 페이지를 열어 둔 동안 1분마다 갱신됩니다

### 💾 자동 저장과 기기 간 동기화
- 모든 변경은 즉시 `localStorage`에 기록되며 새로 고쳐도 사라지지 않습니다
- Cloudflare에 배포하면 클라우드 동기화가 추가됩니다. `localStorage`는 여전히 주 저장소이고(즉시 반영, 오프라인 가능) 클라우드는 백그라운드에서 동기화합니다
- 양쪽이 모두 바꿨다면 **항목 단위로 자동 병합**됩니다(예: 내가 편집하는 동안 공유 상대가 체크를 넣은 경우). 선택을 요구받는 것은 *같은 항목*을 양쪽이 바꿨을 때뿐입니다
- 클라우드 쓰기는 데이터베이스 수준의 compare-and-swap을 사용하므로, 동시에 써도 누군가의 변경이 조용히 사라지지 않습니다
- API를 찾을 수 없거나(단독 실행) 로컬 저장소가 차단된 경우(Claude Artifact 샌드박스) 자동으로 축소 동작하며 기능은 유지됩니다
- **백업 내보내기 / 가져오기**: 페이지 하단에서 전체 데이터를 JSON으로 내보내거나 백업 파일에서 복원할 수 있습니다
- **홈 화면에 추가**: 배포 후에는 PWA를 지원하며 오프라인에서도 열립니다
- **캘린더 구독(ICS)**: 비공개 링크를 만들어 Google·Apple 캘린더에 일정을 구독할 수 있습니다. 회의는 시각이 포함되고 프로젝트 작업은 기간 일정으로 들어가며, 동기화할 때마다 갱신됩니다. 링크는 언제든 다시 만들거나 비활성화할 수 있습니다

## 기술 노트

- 프런트엔드는 의존성이 전혀 없는 단일 HTML 파일(HTML + CSS + 바닐라 JavaScript)로 단독으로 동작합니다
- 유일한 외부 자원은 Google Fonts CDN(JetBrains Mono + Noto Sans TC)이며, **렌더링을 막지 않는 방식으로 불러옵니다.** 폰트가 아직 도착하지 않았거나 아예 닿지 않아도, 빈 화면에서 기다리지 않고 시스템 폰트로 그립니다
- 체크는 즉시 반응하고, 저장과 클라우드 동기화는 백그라운드에서 이뤄집니다
- 반복 항목은 “오커런스 엔진” 방식입니다. 저장하는 것은 기준일과 규칙뿐이고 실제 발생일은 그릴 때마다 펼치며, 회차별 조정은 `occKey`를 키로 삼아 상위 항목에 기록합니다
- 백엔드는 Cloudflare Worker + D1이며 이메일/비밀번호 인증은 자체 구현입니다. 세션은 데이터베이스(해시만)에 두어 즉시 무효화할 수 있습니다

```
public/index.html      본체 앱(단일 파일, 더블클릭으로 열림)
public/login.html      로그인 / 가입(Turnstile 포함)
public/admin.html      계정 관리(관리자 전용)
src/index.js           라우팅과 접근 제어
src/crypto.js          PBKDF2 비밀번호 해시, 토큰 생성
src/session.js         세션 생성 / 조회 / 파기
src/turnstile.js       Turnstile siteverify
src/handlers/          auth / state / admin / share API
schema.sql             D1 테이블 정의
wrangler.jsonc         Worker 설정과 바인딩
tests/                 오커런스 엔진·3방향 병합·낙관적 잠금(node:test, 의존성 없음, npm test)
tools/                 공식 업무 달력을 해석하는 스크립트(매년 공휴일 갱신용)
public/sw.js           service worker(홈 화면 / 오프라인)
```

전체 아키텍처와 데이터 모델은 [`工作排程確認系統_專案說明.md`](./工作排程確認系統_專案說明.md)(번체 중국어)를 참고하세요.

## 알려진 제한

| 제한 | 내용 |
|---|---|
| 단독 실행 시 저장 범위 | 배포하지 않으면 데이터는 *이 브라우저에만* 저장되며 기기를 넘나들지 않습니다. 브라우저 데이터를 지우면 함께 지워집니다 |
| 동기화 충돌 | 마지막으로 동기화한 내용을 기준으로 항목 단위로 병합합니다. 선택을 요구받는 것은 같은 항목을 양쪽이 바꿨을 때뿐입니다 |
| 공휴일 | 주말은 자동 판정. 공휴일은 공식 발표된 연도만 내장되어 있습니다(현재 2026년). 다른 연도는 한 번에 붙여넣을 수 있습니다 |
| 주말 근무일 | 지원됩니다: “근무일” 목록에 넣은 주말은 근무일로 처리되어 반복이 그것을 건너뛰어 미뤄지지 않습니다 |
| 간트 차트 | 막대 끌기는 지원하지 않습니다. 날짜는 작업 표에서 변경합니다 |
| 반복 주기 변경 | 매월 ↔ 분기를 서로 바꾸면 해당 항목의 회차별 완료 / 날짜 덮어쓰기 / 건너뛰기 기록이 초기화됩니다(저장 전에 경고가 표시됩니다) |
