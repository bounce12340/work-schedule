# 業務スケジュール管理システム

[繁體中文](./README.md) ・ [English](./README.en.md) ・ **日本語** ・ [한국어](./README.ko.md)

HTML ファイル 1 つで動く業務スケジュール管理ツールです。タスク・会議・繰り返し項目・月間カレンダー・ガントチャートがすべて 1 ファイルに収まっています。ダウンロードしてブラウザーで開くだけで使えます。

> 純粋なフロントエンド。依存関係なし、インストール不要。Node.js もサーバーもデータベースも要りません。

## 使い方

### 方法 1 — スタンドアロン（インストール不要）

1. [`public/index.html`](./public/index.html) をダウンロード
2. 任意のモダンブラウザーで開く

データはそのブラウザーの `localStorage` に保存され、再読み込みしても消えません。

### 方法 2 — Cloudflare へデプロイ（複数ユーザー＋端末間同期）

```bash
npm install
npx wrangler d1 create work-schedule-db   # 作成済みならスキップし、id を wrangler.jsonc に記入
npm run db:init                            # テーブル作成
```

Turnstile ウィジェット（ボット対策）を作成します:

```bash
npx wrangler turnstile widget create "work-schedule" --domain <あなたのドメイン> --domain localhost --domain 127.0.0.1 --mode managed
```

コマンドが **sitekey**（公開情報。`public/login.html` の `SITEKEY` に記入）と **secret**（機密）を出力します。
続いて 2 つの secret を設定します:

```bash
npx wrangler secret put TURNSTILE_SECRET
```

```bash
npx wrangler secret put ADMIN_EMAILS
```

`ADMIN_EMAILS` は管理者メールアドレスのカンマ区切りリストです。ここに載っているアカウントは**登録した時点で承認済みの管理者になります**。
これがないと最初のアカウントを承認できる人がおらず、システムがデッドロックします。

> この 2 つを `vars` ではなく secret にしているのは、`vars` はバージョン管理に入ってしまう（公開リポジトリならメールアドレスも公開される）ことと、
> ダッシュボードで編集した `vars` が次回の `deploy` で上書きされるためです。

最後にデプロイします:

```bash
npm run deploy
```

**`TURNSTILE_SECRET` が未設定のときは、登録もログインもすべて拒否されます**。通してしまえばボット対策が形だけになるためです。

ローカル開発に本物の鍵は不要です。`.dev.vars` には Cloudflare 公式のテスト鍵が入っています（このファイルは gitignore 済み）。

### デプロイのトラブルシューティング

**登録またはログインが Error 1101（Worker threw exception）を返す** — Workers 本番環境の PBKDF2 反復回数の上限は 100,000 で、超えると `NotSupportedError` が投げられます。しかも**ローカルの workerd はこの制限を強制しない**ため、ローカルでは再現できません。症状・調査過程・修正は
[事故記録: 本番の登録が必ず Error 1101 を返す](docs/postmortems/2026-07-30-register-error-1101.md) を参照してください。

## 機能

### 📋 スケジュール
- **グループ**: 日付を持たない分類ラベル。作成・改名・削除が可能
- **項目**: 3 種類 — 🟢 タスク、🟣 会議、🟠 課題。いずれも任意の時刻と**リンク**（会議 URL、資料など。一覧から直接開けます）を持てます
- **複数日にまたがる項目**: 繰り返しでない項目には終了日を設定できます（例: 8/22–8/26 の出張）。期間中の各日がカレンダーに表示され、完了状態は期間全体で共有、進行中は期限超過に数えません
- 年 / 四半期 / 月 / 特定日の 4 種類の範囲フィルター
- **完了した項目は下部の「完了」セクションに格納**され、上部にはまだ残っている作業だけが並びます
- **繰り返し**: 毎週／隔週（曜日は複数選択可）、毎月（日付指定または「第 N ○曜日」）、四半期ごと、毎年。祝日に当たったときは後ろ倒し・前倒し・調整なしから選べ、終了日または回数の上限も設定できます
- 特定の 1 回だけ日付を変更したりスキップしたりでき、他の回には影響しません
- 独自の祝日リスト（土日は自動で祝日扱い）: **国民の祝日をワンクリックで読み込み**（2026 年分を内蔵。出典は台湾行政院人事行政総処の公式業務カレンダー）、複数の日付をまとめて貼り付けることも可能
- キーワード（タイトルまたはグループ）・種類・完了状態による**検索とフィルター**

### 📅 カレンダー
- 今日が明確に分かる月間グリッド
- 会議は時刻順に表示。タスクと課題はセル上で直接チェックできます
- **スマートフォンでは Google カレンダー方式**: セルにはその日の内容を表す色付きドットだけを表示し、日付をタップすると下に全内容が開きます。50px 幅のセルに 3〜4 行の文字を詰め込んでも、スマートフォンでは読める情報になりません
- 日付をタップすると項目カードと**日次メモ**欄が開きます（書式設定対応。下記参照）

### 📊 プロジェクト（ガントチャート）
- 複数プロジェクト対応。進捗率と今日を示す線を含むタイムラインバー
- **タイムラインは横スクロール**でき、週／月／四半期／年の 4 段階でズームを切り替えられるため、長期・年をまたぐプロジェクトも読めます。年の境界には明確な区切り線があり、「今日へ移動」もワンクリックです
- 日付と進捗はタスク表で直接編集でき、チャートに即座に反映されます
- 各タスクは**サブタスク**に展開でき、その場合の進捗はチェック状況から自動計算されます（手動入力欄は読み取り専用になります）
- プロジェクトはドロップダウンで切り替えます
- プロジェクトメモは自動保存されます（書式設定対応。下記参照）

### ✍️ 書式設定（日次メモとプロジェクトメモ）
- 太字・斜体・下線・取り消し線、箇条書きと番号付きリスト、蛍光ペン・文字色・文字サイズ、引用・リンク・コード、書式のクリア
- ツールバーは**既定で折りたたまれています**。`Ctrl+Shift+X` か欄の下のボタンで切り替えられ、設定はこの端末に記憶されます
- Web から貼り付けた内容は自動的に整理され、対応している書式だけが残ります

### 🔔 ダッシュボードとリマインダー
- 上部に常時表示: 本日分・今週分・本日の会議・期限超過
- ページを開くと本日の未完了項目がポップアップし、ベルのボタンには未読数が表示されます
- 右上で**ライト／ダーク**を切り替え。既定ではシステム設定に従います
- スマートフォンではナビゲーションが画面下部に固定され、フォームとダイアログはタッチ操作向けに調整されています
- 右上で**日本語環境では英語表示**に切り替え可能（既定はブラウザーの言語に従い、繁体字中国語と英語を切り替えます）

### 👥 ユーザーと権限（デプロイ後に有効）
- ユーザーはメールアドレスとパスワードで自分で登録します。登録ページには Cloudflare Turnstile のボット対策があります
- **登録後は管理者の承認が必要**で、未承認のアカウントはセッションを受け取れません
- 役割は 2 つ: **利用者**（自分のスケジュールのみ）と**管理者**（アカウント管理も可能）
- 管理者はアカウントの承認・却下・停止・削除と役割変更ができますが、**誰のスケジュール内容も見られません**
- アカウントを停止・削除すると、その人の全端末が即座にログアウトされます
- パスワードは PBKDF2-SHA256（100,000 反復。Workers プラットフォームの上限）のハッシュで保存し、平文は保持しません
- 各アカウントは**空の画面**から始まり、他人のデータは一切見えません

### 🔗 共有（デプロイ後に有効）

- 任意の項目・**グループ（配下の全項目を含む）**・プロジェクトで **🔗** を押し、相手のアカウントのメールアドレスを入力します
- 権限は 2 段階: **閲覧可**（読み取り専用）と**操作可**（完了・サブタスクのチェック、進捗の変更）
- 改名・日付変更・削除は常に所有者だけができます
- 共有されるのは複製ではなく同じデータなので、双方が常に同じものを見ます。所有者はいつでも取り消せます
- 受け取った共有は「共有」ページにまとまり、自分のスケジュールやカレンダーには混ざりません
- **操作記録**: 共有項目を誰がいつ変更したかが 90 日間残ります。「共有」タブには未読数が表示され、ページを開いている間は毎分更新されます

### 💾 自動保存と端末間同期
- 変更は即座に `localStorage` へ書き込まれ、再読み込みしても消えません
- Cloudflare へデプロイするとクラウド同期が加わります。`localStorage` が主たる保存先のまま（即時反映・オフライン可）、クラウドはバックグラウンドで同期します
- 両側が変更していた場合は**項目単位で自動マージ**されます（例: あなたが編集している間に、共有相手がチェックを入れた）。選択を求められるのは*同じ項目*を双方が変更したときだけです
- クラウドへの書き込みはデータベースレベルの compare-and-swap を使うため、同時書き込みで誰かの変更が黙って消えることはありません
- API が見つからない（スタンドアロン）場合やローカルストレージが禁止されている（Claude Artifact のサンドボックス）場合は自動的に縮退し、機能は損なわれません
- **バックアップの書き出し／読み込み**: ページ下部から全データを JSON に書き出し、バックアップファイルから復元できます
- **ホーム画面に追加**: デプロイ後は PWA に対応し、オフラインでも開けます
- **カレンダー購読（ICS）**: プライベートなリンクを生成して Google／Apple カレンダーに購読できます。会議は時刻付き、プロジェクトのタスクは期間イベントとして、同期のたびに更新されます。リンクはいつでも再生成・無効化できます

## 技術メモ

- フロントエンドは依存関係ゼロの単一 HTML ファイル（HTML + CSS + バニラ JavaScript）で、単体で動作します
- 唯一の外部リソースは Google Fonts CDN（JetBrains Mono + Noto Sans TC）で、**描画をブロックしない方法で読み込みます**。フォントが届いていない、あるいは到達できない場合でも、白い画面で待たずにシステムフォントで描画します
- チェックの反応は即時で、保存とクラウド同期はバックグラウンドで行われます
- 繰り返し項目は「オカレンスエンジン」方式です。保存するのは基準日とルールだけで、実際の発生日は描画のたびに展開し、1 回ごとの調整は `occKey` をキーとして親項目に記録します
- バックエンドは Cloudflare Worker + D1 で、メール／パスワード認証は自前実装です。セッションはデータベース（ハッシュのみ）に持つため、即座に失効させられます

```
public/index.html      本体アプリ（単一ファイル。ダブルクリックで開けます）
public/login.html      ログイン／登録（Turnstile 付き）
public/admin.html      アカウント管理（管理者のみ）
src/index.js           ルーティングとアクセス制御
src/crypto.js          PBKDF2 パスワードハッシュ、トークン生成
src/session.js         セッションの作成／参照／破棄
src/turnstile.js       Turnstile siteverify
src/handlers/          auth / state / admin / share の各 API
schema.sql             D1 のテーブル定義
wrangler.jsonc         Worker の設定とバインディング
tests/                 オカレンスエンジン・3 方向マージ・楽観ロック（node:test、依存ゼロ、npm test）
tools/                 公式業務カレンダーを解析するスクリプト（毎年の祝日更新用）
public/sw.js           service worker（ホーム画面／オフライン）
```

アーキテクチャとデータモデルの詳細は [`工作排程確認系統_專案說明.md`](./工作排程確認系統_專案說明.md)（繁体字中国語）を参照してください。

## 既知の制限

| 制限 | 内容 |
|---|---|
| スタンドアロン時の保存範囲 | デプロイしない場合、データは*このブラウザーのみ*に保存され、端末をまたぎません。ブラウザーのデータを消すと一緒に消えます |
| 同期の競合 | 最後に同期した内容を基準に項目単位でマージします。選択を求められるのは同じ項目を双方が変更したときだけです |
| 祝日 | 土日は自動判定。国民の祝日は正式に公表済みの年度のみ内蔵しています（現在は 2026 年）。他の年度はまとめて貼り付けられます |
| 休日出勤日 | 対応済み: 「出勤日」リストに追加した土日は勤務日として扱われ、繰り返しがそれを飛び越えて後ろ倒しになりません |
| ガントチャート | バーのドラッグには対応していません。日付はタスク表から変更します |
| 繰り返し頻度の変更 | 毎月 ↔ 四半期を入れ替えると、その項目の 1 回ごとの完了／日付上書き／スキップの記録がリセットされます（保存前に警告が出ます） |
